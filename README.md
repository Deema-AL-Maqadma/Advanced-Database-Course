# 📚 Course Overview

The Advanced Database Systems course explores modern database technologies, advanced database architectures, performance optimization techniques, distributed database management systems, business intelligence, data warehousing, and big data technologies.

The course combines theoretical foundations with practical implementation using Oracle Database and Oracle APEX, allowing students to design, develop, optimize, and manage database-driven applications.

# 🚀 Final Project

The final project focused on designing and implementing a complete Contact Management System using Oracle Database and Oracle APEX.

Project components included:

## Database Design

- Creating the CONTACTS table
- Defining attributes and constraints
- Inserting sample data

## PL/SQL Programming

### Function

- VALIDATE_EMAIL
- Validates email format before storing data

### Procedure

- ADD_CONTACT
- Inserts new contact records into the CONTACTS table

## Oracle APEX Application

The application contains three main pages:

### Contacts List

- Interactive Report
- Displays all contacts
- Shows contact information
- Allows users to navigate to detail pages

### Add Contact

- Form for inserting new contacts
- Uses validation mechanisms
- Integrates with PL/SQL procedures

### Contact Details

- Displays complete contact information
- Opens when a contact is selected

## Additional Features

- Required Field Validation
- Email Validation Using PL/SQL Function
- Dynamic Actions
- Authorization Scheme
- User Access Control

The project demonstrates how Oracle Database and Oracle APEX can be integrated to create a fully functional database-driven application.
